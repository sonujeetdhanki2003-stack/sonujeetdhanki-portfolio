KINGSIDE CHESS

Chess, the way the big apps do it. Made solo.

Role
Product, design, engine integration, server, builds
Platforms
Android · Windows · Web
Built with
JavaScript · Stockfish (WASM) · PWA · Electron · Android · Realtime server
Current version
v1.8.3 · 2026

The idea

A full chess app: play friends online or get a Quick Match, climb the ratings, train against eight bot personalities, learn from lessons and daily puzzles, then get a Game Review that labels every move.

Get it on itch.io →Play in browser →Landing page →View source on GitHub →

What's inside

01

Online play

Room links for friends, Quick Match pairing, rematches and chat.

02

8 bot personalities

From a friendly beginner to a strong engine, each with its own name and style.

03

Game Review

Accuracy scores, opening names and move labels from Brilliant to Blunder.

04

Learn & puzzles

35 lessons in English and Hindi, a daily puzzle and Puzzle Rush.

05

Ratings & more

Ratings, leaderboard, streaks, achievements, tournaments and board themes.

06

Everywhere

Android APK, Windows app and a web app you can install.
