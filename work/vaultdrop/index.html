VAULTDROP

AirDrop for everything. No internet needed.

Role
Design, protocol, apps, builds
Platforms
Android · Windows · Any browser · Android TV
Built with
WebRTC · Local HTTP · End-to-end encryption · Android · Electron · Go (Lite)
Current version
v1.5.2 · 2026

The idea

Open-source, local-only file sharing between Android, Windows, iPhone and TVs. Devices on the same Wi-Fi or hotspot find each other and send files directly. Nothing goes through a cloud.

Get it on itch.io →Website →

What's inside

01

Offline first

Works on any local network or a phone hotspot, with no account and no internet.

02

Encrypted

Every transfer is end-to-end encrypted, with a short code to confirm devices.

03

Drop Queue

Queue files for a device that is away; they go when it comes back.

04

Rooms & clipboard

Share with a group, or send copied text between devices.

05

Big screens too

Android TV receive screen with QR pairing and a media grid.

06

VaultDrop Lite

A compact single-file Windows build, about 8 MB.
